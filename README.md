# Guestbook

Простое веб-приложение «Гостевая книга» на Flask. Позволяет оставлять
сообщения и видит их список на главной странице. Данные хранятся в
PostgreSQL.

## Стек

- Python 3.12, Flask
- PostgreSQL (через psycopg2)

## Локальный запуск (без Docker)

1. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
2. Поднимите PostgreSQL любым удобным способом и создайте пустую базу
   данных (саму таблицу приложение создаст автоматически при старте).
3. Задайте переменные окружения (см. `.env.example`) и запустите:
   ```
   python app.py
   ```

Приложение слушает **порт 5000**.

## Переменные окружения

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `DB_HOST` | хост PostgreSQL | `localhost` |
| `DB_PORT` | порт PostgreSQL | `5432` |
| `DB_NAME` | имя базы данных | `guestbook` |
| `DB_USER` | пользователь БД | `guestbook` |
| `DB_PASSWORD` | пароль БД | `guestbook` |
| `DB_CONNECT_RETRIES` | сколько раз пытаться подключиться к БД при старте | `10` |
| `DB_CONNECT_DELAY` | пауза между попытками подключения, сек | `2` |

## Схема базы данных

Приложение само создаёт таблицу `entries` при старте (если её ещё нет)
— отдельно применять какую-либо SQL-схему не требуется, достаточно,
чтобы к моменту старта существовала сама база данных, указанная в
`DB_NAME`.

## Проверка состояния

`GET /health` — возвращает `{"status": "ok"}`, если приложение работает
и может подключиться к базе данных, иначе `{"status": "error", ...}` с
кодом 503.
